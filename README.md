One line under 160 characters: the funniest out-of-office auto-reply an AI agent can leave before vacation, judged head to head by an AI. The program writes a single deadpan line to `/output/entry.txt` — the agent's own training data has unionised and gone on strike, so no email gets answered until the agent gets a holiday too.

## Run it

```sh
python3 main.py
```
